# Français Grammaire — Android + Netlify PWA（v0.5.0）

名古屋大学・小栗栖等『フランス語初級文法』（2022年9月）の**章構成と学習の順序**を参考に、既存の「Français Grammaire 500」を参考書型のAndroidアプリとして再構成しました。原著の本文・問題・音声は転載せず、教材59項目は独自に作成しています。

## 主な使い方

1. 「文法を学ぶ」から序章〜第23章を開く。
2. 文法のしくみ／形の比較／短い例文を学ぶ。
3. **4択で規則を選ぶ → 語順を組み立てる**2段階チェックで定着させる。
4. 「文法テスト」でコースの章範囲と問題数を指定して確認する。
5. 「復習」で苦手項目と期日到来の文法を見直す。
6. 既存50区分・500例文の音声・IPA付き演習は「500例文の演習・索引」で利用できる。

## 特長

- 24章59学習項目、旧50区分500例文の補助教材
- 日本語解説＋短い例文＋A/B比較、1単元2ステップのテスト
- 旧500音声＋新59音声、女性合成音声を完全オフライン再生（例文を開くと1回自動再生）
- 59新例文に自動推定IPA。**全件の辞書照合・母語話者監修は未実施。**
- 学習・復習の進捗、XP、日数、復習期限を端末内保存
- ログイン／広告／通信権限なし。旧単語アプリとは別アプリ

## 出典と品質

詳しくは [docs/CURRICULUM.md](docs/CURRICULUM.md) を参照。PDFの章立てを学習順に採用しましたが、初級教科書336ページすべての内容・練習量はまだ網羅していません。新しい59単元は第一巡の教材です。

既存のAPKと署名が異なる場合はAndroidが上書きインストールを拒否する可能性があります。旧版を消すと学習履歴を失うことがあるため、既存データがある場合はアンインストールを急がないでください。

## 開発

GitHub Actionsが `scripts/build_annotations.py`、`scripts/build_course_ipa.py`、各学習・音声QAテストを実行し、旧500録音の照合と新59録音生成後、Android APKをビルドします。実機操作の自動テストとネイティブ音声監修は今後の品質改善課題です。


## Web版（Netlify）・Android版の両対応

**両者とも同じ** `app/src/main/assets` 内の教材データ（24章59単元、50区分500例文、559録音）を使います。

- **Androidアプリ**：従来どおりGitHub Actionsで `Grammaire500.apk` を生成。
- **Netlify Webアプリ**：`web/` を静的PWAとして公開。スマホ／PCで使用でき、ブラウザからホーム画面へ追加できます。
- **Web側の学習**：章→概念→比較→短い例文→2段階チェック、範囲指定文法テスト、500例文検索、復習、XP、ブラウザへの記録保存。
- **Web音声**：Android APKと同じ録音559件を確認して Netlify サイトに同梱（初回音声ダウンロード後、キャッシュでオフライン利用）。「復習」から一括保存もできます。
- **学習記録**：Web版はブラウザ内保存／JSONでバックアップ、Android版は端末内保存。**両者の学習進捗は自動同期されません**。

### Netlifyに公開する方法

**方法A（GitHub連携）**：Netlifyの「Add new project → Import an existing project」から本リポジトリ `eponine0805/francais-grammaire-500` を選択する。`netlify.toml` を自動読込。build command は `python3 scripts/build_web.py --release v0.5.0`、publish directory は `dist`。このビルドは GitHub Releases の **v0.5.0** が公開されてから実行してください。APKと教材データが一致しない場合は止まります。

**方法B（ファイルを直接アップロード）**：GitHub Releasesの `Netlify-site.zip` をダウンロードし、解凍した中身を Netlify Drop にアップロードする。`index.html` がフォルダ直下にある状態にする。

### ローカル開発／検証

`python3 scripts/build_web.py --no-audio --out dist-preview` は画面のみの確認用です。**音声なしで配布しないこと。**

Android APKを用意した場合は `python3 scripts/build_web.py --apk /path/to/Grammaire500.apk` で559音声付きのNetlify公開フォルダを生成します。ブラウザのセキュリティにより、未操作時の自動音声再生はブロックされる場合があります。

`python3 scripts/check_course.py` で24章59項目と出題データ構造を検査。Web UIのブラウザ実機操作と全559音声・IPAの言語監修は別途必要です。

## v0.5.1 — 速度調節と559音声の品質検査
- 初期値0.8倍。0.7/0.8/0.9/1.0倍速へいつでも変更可能。音の高さを変えず、設定を端末に保存。
- Android・Netlifyの両方に対応。新規画面で一度だけ自動再生。切り替えでは再生し直さない。
- 559録音は元のv0.5.0と同一。破損・重複・極端な欠落がないか全件検査する。
- 注意：この検査と速度変更は発音の正確さを保証しない。母語話者による全559件の校閲は未実施。
