# Français Grammaire — Android + Netlify PWA (v0.6.1)

名古屋大学・小栗栖等『フランス語初級文法』（2022年9月版）の**序章＋23章の順序**を参考にした、AndroidとNetlifyの両対応のフランス語初級文法教材です。原著の文章・問題・音声を転載せず、講義・例文・演習問題はアプリ専用に独自作成しました。

## 学習の流れ

1. 24章の目次から単元を選択する（59単元）。
2. **3節の文章による説明**で使い方・作り方・よくある誤りを理解する。
3. 形の対比と**7つの解説つき例文**を読む（基本例文1、関連例文6）。
4. 文章の内容を思い出しながら**20問のテスト**を解く。解答後はすぐ正誤・根拠を表示。次問ボタンは画面下部へ固定。
5. 20問中16問以上で合格。間違えた設問だけ再挑戦でき、学習結果・中断中セッションは端末内に保存される。
6. 文法テストの範囲選択、旧500例文の復習、音声の再生速度（0.7～1.0倍）などは維持。

### 20問の構造と問題数

1単元につき「規則を選ぶ」1問、「基本文の語順」1問、関連6例文×「空欄補充・語順・意味」の3形式＝18問、計20問。**59×20＝1180問**。
これは1180種類の異なるフランス語の文を指すのではなく、**7つの例文に何度も異なる方向から取り組む定着型の出題方式**です。

## 開発・検証

```sh
python3 scripts/build_course_ipa.py   # eSpeak-NGを必要とする
python3 scripts/build_intensive.py
python3 scripts/test_intensive.py
python3 scripts/check_course.py
node --check web/app.js
```

`intensive.json` は `scripts/lecture_notes.txt` の59単元個別講義、`scripts/custom_drills.txt` の不足部分の新規例文、既存500例文から毎回決定的に生成されます。AndroidとWebで**同じJSON**を使います。GitHub ActionsはAndroidのAPKとNetlify用ZIPの双方を出力します。Netlifyは `netlify.toml` が提供するコマンドで `dist/` を公開します。

Webのバックアップはこれまでの `fr-grammaire-2026-learning-v1` を継続使用します。Androidも既存アプリIDと学習記録用のSharedPreferencesを維持。Android・Web間の自動同期は提供しません。

### 音声の注意

既存500例文＋コース基本59文の計559の録音は従来の女性合成音声をそのまま利用します。**新たな例文の一部には音声を追加していません。** 再生速度は初期0.8倍で、音声内容の正確性まで改善したものではありません。IPAと既存録音には専門家の全件校閲がありません。

### 校閲の注意

構文の自動検査、全1180設問のデータ整合性、Web UIのChromium操作検査を行いますが、**59単元の講義・文例・1180設問に対するフランス語教師／母語話者の完全監修は未実施**です。日本語の講義や正答の別解があり得る点には留意してください。
