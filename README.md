# Français Grammaire 500

## v0.4.1 — 学習画面・テスト範囲の改善

- **例文画面を開くと女性音声が自動で1回再生**。次の例文へ進めるたび新しい文を1回再生。手動再生も可能。
- 例文の前後移動を画面下部に固定。スクロールせず切り替えられる。
- **文法テストの出題範囲を指定**：開始・終了単元（1〜50）、20〜100問（10問刻み）または範囲内の全問。指定範囲内で重複なくランダム出題。
- 解説の「200字以内」の硬い制限を廃止し、例文ごとの要点を短く表示。単元の解説は別表示。
- 4択テストと語順並べ替えテスト。回答直後に緑／赤で正誤を表示し、次問は画面下部の固定ボタン。
- 語順チップ選択・取り消しでスクロール位置が戻らないよう修正。全問テストの大量誤答は結果画面の表示を30件までに制限し、復習対象は全件保持。
- 正答数、苦手履歴、XP、学習日数、復習予定、テスト途中を端末内のSharedPreferencesに保存。既存の記録キーは継続使用。
- 50単元の**全1,275範囲×10パターン＝12,750ケース**の出題数・範囲シミュレーション。音声は同じ500例文を再利用。

### 注意

本アプリは学習プレビュー版。IPAはeSpeakの自動推定を辞書と発音規則に照らして28件修正。全500件のネイティブ話者による監修は未実施。Android実機での画面自動操作試験も未実施です。APKはデバッグ署名のため、署名の異なる旧APKをアンインストールすると学習履歴が消える場合があります。

### 検証

`python3 scripts/build_annotations.py && python3 scripts/check_catalog.py && python3 scripts/test_learning_flow.py && python3 scripts/check_quiz_ranges_v040.py`

詳細：`docs/QA_v040.md`

## IPA修正と残る課題
v0.4.0のAPK内の500 IPAをチェックし、半母音 /ɥ/ の系統的誤り、誤ったリエゾン、英語発音へのフォールバックなど**28文を修正**。再生成後、`scripts/test_ipa_review.py` が同種の既知エラーを検出します。辞書等で確認できた範囲での修正であり、全500文のIPA・音声の学術的な精度を保証しません。IPAとAI音声は異なるエンジンで生成しており、実際の録音との全件一致も未確認。

## v0.4.2 検証の厳格化
以前のワークフローで連続したテストコマンドが1つのシェル行に折り畳まれる問題を修正。生成／教材／IPA／学習フロー／出題範囲の各テストを個別に実行し、異常終了時にはAPKを公開しません。
