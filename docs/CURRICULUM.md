# カリキュラムと出典 — v0.5.0

## 出典に対する忠実性

ユーザー提供のPDF『フランス語初級文法』（小栗栖等、名古屋大学、2022年9月版、336ページ）を構成上の基準としました。具体的には序章の綴りと音、第1章「名詞と冠詞」から第23章「接続法・単純過去・前過去」まで、**学習の順序と扱うテーマ**を反映しています。

原著の練習問題文・例文・音声をコピーしているわけではありません。アプリの新59単元には、学習目標、要点説明、比較する2表現、短いフランス語例文、日本語訳、文法上の根拠、理解チェックを独自に書き下ろしています。原著の音声は配布対象が制限されているため利用していません。

## 教材構造

- **コース**：序章＋23章／全59短時間単元。教科書の章立てと概念の依存関係を優先。
- **学習単元**：①規則の核を理解 → ②形の違いを対比 → ③文で確認 → ④選択＋語順組み立て。1問で覚えたと認定せず、二段階で確認。
- **復習**：誤答項目を保存。初回から1日、3日、7日、14日、30日を目安に再出題。
- **出題範囲**：新コースでは序章〜第23章を指定し10〜100問／範囲内の全問を選択可能。元の500例文テストも維持。
- **既存資産**：50分類の500例文、旧音声500件、旧IPAと学習履歴キーは維持。主コースとは別に「補助演習・索引」として開ける。

## 意図的な制限

- 59単元は全336ページの文章や練習問題を再現するものではなく、**章構成に沿った重要項目の第1巡**です。特に第21〜23章の発展項目は要点確認に留めています。
- 59新例文の音声はSupertonic 3（F2）の合成音声を新規生成。原著の音声は利用していません。
- 59新例文のIPAはeSpeak自動推定をもとにした参考表記。**全件の音声とIPAの照合・母語話者監修は未実施**。既存500文にも同じ限界があります。
- APKはGitHub Actionsでデバッグ署名でビルド。署名が旧版と異なる場合、上書き不可。古い版をアンインストールすると端末内の学習記録が消える可能性があります。バックアップ機能は未実装です。
- コード／データの自動テストは人が実際にタップしたときのUXを保証しません。実機での操作確認が必要です。

## 教科書から抽出した指針

- 第1章（PDF p.15–26）：「性と数→冠詞→表→名詞との組み合わせ」。単独の例文暗記で済ませない。
- 第3章（p.41–50）：êtreの変化表、主語代名詞、à/deの縮約。**主語によって活用が変わる**事実を図式化。
- 第4〜6章（p.51–88）：avoir→疑問・否定→規則動詞。最小構文の変形で確認する。
- 第9〜12章（p.109–174）：目的語と代名詞の位置→複合過去→代名動詞。表現・形・語順を切り分ける。
- 第16〜18章（p.213–248）：複合過去/半過去/大過去と単純未来を比較する。
- 第21〜23章（p.273–320）：条件法、間接疑問文、接続法。上級文法を一度に暗記させず、初級者が構造を識別できるようにする。

## 品質保証で検証するもの

教材：24章と59単元のID、テーマ分配、各単元での正解一意性、重複、例文語順、章範囲の出題条件。
実装：導入→章→概念→2段階チェック、即時正誤、戻る動作、ローカル記録、テスト区分、オフライン音声ファイル数。
音声・IPA：コンテンツへのID対応、音声の存在と大きさ、既知の表記誤りの自動回帰検査。

**これらのチェックは、言語内容の完全な正確性の証明ではありません。**
