# v0.4.0 監査記録

## 実装
- 例文画面オープン時に音声を1回再生、手動再生も維持。
- テスト開始単元／終了単元、20〜100問、範囲内全問を指定可能。
- 例文前後・テスト次問を画面下部に固定。
- 語順チップ追加時にスクロール位置を維持。
- 解説の200字強制・見出しを廃止。例文専用の短い説明を維持。
- 誤答一覧は30件まで画面表示、誤答の全件復習は維持。

## データシミュレーション
- 文法50単元・例文500文。
- 1,275個の範囲を10方式ずつ、計12,750ケースを検査。
- 各範囲の問題数、出題単元、ID重複なしを確認。
- IPA500件、音声500件は別途APK展開検査。

## 検査上の限界
- UI実機操作はまだ自動テストしていません。
- 500音声とIPAの実際のフランス語発音の正確性は保証していません。IPAは自動推定です。
- デバッグ署名のAPK更新時には学習履歴の消失リスクがあります。
